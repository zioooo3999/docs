## Overview

The Tempe Park platform is organized into two primary application directories: **Backend (`web-be`)**, powered by Strapi CMS, and **Frontend (`web-fe`)**, built with Next.js App Router.

---

## Directory Breakdowns

<Tabs>
  <Tab title="Backend (Strapi CMS)">
    ### Backend Project Structure (`web-be`)

    The backend leverages Strapi's modular architecture to manage 24 content collections, database migrations, dynamic components, and MinIO storage integrations.

    | Directory / File | Description & Function |
    | :-- | :-- |
    | `config/` | Application configurations (server, database connection pooling, admin panel, `@strapi/provider-upload-aws-s3` plugin). |
    | `src/api/` | Content Types (24 collections). Each collection includes its own controllers, routes, services, and schema definitions. |
    | `src/components/` | Reusable component and dynamic-zone field definitions used by the CMS content builder. |
    | `database/` | Database migration scripts and schema change definitions. |
    | `public/` | Local static assets and fallback upload directory (used when MinIO object storage is disabled). |
    | `scripts/` | Utility scripts for database seeding, data transformation, and automation. |
    | `types/` | Auto-generated TypeScript interfaces and type definitions (`generated/`). |
    | `dist/` | Compiled JavaScript build output generated by running `strapi build` or `npm run build`. |
    | `Dockerfile` | Container configuration and multi-stage build image definition for backend deployment. |
  </Tab>
  <Tab title="Frontend (Next.js)">
    ### Frontend Project Structure (`web-fe`)

    The frontend utilizes Next.js App Router to dynamically fetch and render CMS content via catch-all routes.

    | Directory / File | Description & Function |
    | :-- | :-- |
    | `app/` | Next.js App Router routes. `[[...slug]]` renders dynamic CMS pages; includes `/search` and internal `/api` routes. |
    | `components/` | Reusable React UI components, page layouts, and dynamic section blocks. |
    | `hooks/` | Custom React hooks for state management, data fetching, and browser utilities. |
    | `lib/` | Core helper functions (`lib/strapi.ts` handles Strapi REST API fetching and resolves media URLs). |
    | `public/` | Static media assets, icons, fonts, and favicon files. |
    | `next.config.mjs` | Next.js build and runtime configuration (image domain whitelisting, headers, optimization). |
    | `tsconfig.json` | TypeScript configuration and path aliases (`@/*`). |
    | `postcss.config.mjs` | Tailwind CSS and PostCSS configuration settings. |
    | `Dockerfile` | Container configuration and multi-stage build image definition for frontend deployment. |
  </Tab>
</Tabs>

## Tech Stack & Architecture Overview

```text
tempe-park/
├── web-be/                 # Strapi CMS (Node.js, TypeScript)
│   ├── config/             # Environment & plugin configuration
│   ├── src/
│   │   ├── api/            # 24 API Collection Types (Controllers, Routes, Services)
│   │   └── components/     # Dynamic Zone UI Components
│   └── Dockerfile          # Backend Container Spec
│
└── web-fe/                 # Next.js App Router (React, Tailwind CSS)
    ├── app/                # [[...slug]] Dynamic Route Handler & App Pages
    ├── components/         # Reusable UI Design System
    ├── lib/                # Strapi API Client (`lib/strapi.ts`)
    └── Dockerfile          # Frontend Container Spec
```
