## Overview

The **Plugins Permissions** setting allows administrators to configure specific access rights and functional privileges for installed system plugins within the CMS (such as _Content Manager_, _Media Library_, _SEO_, or _Navigation_).

By defining permissions at the plugin level, administrators can control which tools and extensions a user role can access or configure, ensuring administrative capabilities remain secure and tailored to each role's workflow.
