## Overview

The **Event / Calendar** module in the Tempe Park CMS is used to manage information about the schedule of events, activities, and special programs held at Tempe Park based on specific dates. This module serves as a tool for managing the activity calendar, which is then displayed on the website so visitors can easily view available schedules and plan their visits.

Through this module, administrators can add and organize various event details—such as event names, dates, operating hours, locations, descriptions, media assets, and supporting notices. With date-driven management, every event is presented in a structured and intuitive format on the visitor-facing platform.

## Main Menu Controls<br /><br />

Here is the primary layout and control functions of the **Event / Calendar** menu:

| No | Field / Element | Function & Description |
| :-: | :-- | :-- |
| **1** | **Search Button** | Click this icon to search for desired keywords across general fields: `title`, `slug`, and `short_description`. |
| **2** | **Filter Button** | Filter entries by specific attributes (e.g., searching within a single specific column). Select a field and enter matching criteria. |
| **3** | **Checkbox Button** | Perform batch operations on multiple records simultaneously, such as bulk publishing, unpublishing, or deleting entries. |
| **4** | **Id** | Unique identifier record for the event/calendar data. |
| **5** | **Slug** | URL-friendly slug string generated for the event record. |
| **6** | **Short\_Description** | Concise summary of the scheduled event or activity. |
| **7** | **Available In** | Indicates available language translations. Click to jump directly to editing localized content versions. |
| **8** | **Status** | Displays whether the event record is currently in `Draft` or `Published` state. |
| **9** | **Multilingual Button** | Switch current workspace view between **English**, **Indonesian**, and **Chinese**. |
| **10** | **Settings** | Customize visible grid columns and field display preferences. |
| **11** | **Create New Entry** | Click to open the creation form and add a new event/calendar record. |
