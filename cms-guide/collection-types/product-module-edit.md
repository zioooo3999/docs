## Overview

The **Edit Data** feature in the Product module allows administrators to update product information currently stored in the system. Changes made here will be reflected on the website front page once saved. This ensures that product details, pricing, and marketplace links remain accurate and up-to-date.

## Form Configuration

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1-2** | **Tabs** | Switch between **Draft** (editable) and **Published** (read-only view). |
| **3** | **product\_name** | Modify the product name. |
| **4** | **product\_category** | Update the product category assignment. |
| **5-6** | **Description** | Edit product details. Use **Expand** to enlarge the text editor. |
| **7-8** | **Publish / Save** | Apply changes to the live site or save as a draft. |

---

## Product Updates

To modify specific product attributes, update the corresponding fields below:

### Product Attributes

- **Images (9):** Update or replace the primary product image.
- **Color (10):** Modify available product color variations.
- **Size (11):** Modify available product size variations.

### Pricing Details

- **Price (12):** Update the current selling price.
- **original\_price (13):** Update the original price for reference or discount calculation.

### Marketplace Integration

Update the direct URLs for external marketplaces:

- **Marketplace\_link\_tokopedia (14):** Update the Tokopedia link.
- **Marketplace\_link\_tiktokshop (15):** Update the TikTok Shop link.
- **marketplace\_link\_shopee (16):** Update the Shopee link.

<Warning>
  Any changes saved here will immediately affect the live product information on the Tempe Park website front page. Verify all data before clicking **Publish**.
</Warning>
