## Overview

The **Create/Setup Education Detail** feature allows administrators to build detailed information pages for educational programs. Utilizing the **Page Builder** mechanism, this module manages content such as program descriptions, schedules, sidebar call-to-actions, and links to other school programs.

<Tip>
  Use **Save button** to keep content as Draft, or **Publish** when the data is ready to appear on the website frontpage.
</Tip>

---

## Form Configuration

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1-2** | **Tabs** | Switch between **Draft** (editable) and **Published** (read-only view). |
| **3-4** | **Title / Slug** | Define the page identity and URL structure. |
| **5-6** | **SEO** | Click `(+)` to configure `metaTitle`, `metaDescription`, and `shareImage`. |
| **7** | **Add Component** | Access structural block components to build the page. |
| **10** | **Multilingual** | Toggle between English, Indonesian, and Chinese. |

## Education Detail Setup

To populate the education program details, follow these steps using the Page Builder:

### Component Configuration

- **Access:** Click **Add a component to blocks** (7) and select the **Experience** component group (11).
- **Initialization:** Click on **Experience Detail** (12) to begin configuring the layout fields.

### Configuration Fields

| Field | Description |
| :-- | :-- |
| **breadcrumb\_parent\_label** | Label for the parent breadcrumb on the education detail page. |
| **sidebar\_label\_about\_program** | Custom title for the "ABOUT THIS PROGRAM" section in the sidebar. |
| **sidebar\_cta\_label** | Label for the CTA button in the sidebar section. |
| **sidebar\_cta\_url** | URL destination for the sidebar CTA button. |
| **schedule\_section\_heading** | Title for the Program Schedule section of the page. |
| **related\_section\_heading** | Title for the "Explore Other School Programs" section. |
| **sidebar\_join\_label** | Section title for the "Join This Program" feature in the sidebar. |
| **related\_item\_readmore\_label** | Label text for the "Learn More" button in the related programs list. |

<Warning>
  Always verify the accuracy of your CTA URLs and program labeling across all language versions before publishing.
</Warning>
