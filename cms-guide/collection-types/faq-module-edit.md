## Overview

The **Edit Data** feature in the FAQ module is used to update or modify questions and answers stored in the system. Administrators can make changes to the content of questions, answers, FAQ categories, and other information as needed.

Changes to data made through this feature will immediately affect the FAQ information displayed on the Tempe Park website after the data is successfully saved, ensuring that the information available to visitors remains accurate, relevant, and up-to-date.

---

## Form Fields & Interface Reference

<Frame>
  ![Edit FAQ Page](/images/0-\(30\).png "Edit FAQ Page")
</Frame>

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1** | **Tab Draft** _(editable form)_ | Switch to this tab when editing active form fields. |
| **2** | **Tab Published** | Read-only view showing the current live content on the frontend. |
| **3** | **Question** | Update the FAQ question text. |
| **4** | **Answer** | Update the detailed answer or response text. |
| **5** | **Category** | Modify the assigned FAQ category. |
| **6** | **Order** | Adjust the numerical sequence number for sorting display order. |
| **7** | **Publish** | Save and deploy changes immediately to the live website landing page. |
| **8** | **Save** | Preserve edits as a **Draft** without publishing them publicly. |
| **9** | **Set up Preview** | Preview content layout on the frontpage before saving modifications. |
| **10** | **Multilingual** | Switch between localized languages (**English**, **Indonesian**, **Chinese**). |

---

## Step-by-Step Procedure

<Steps>
  <Step title="Review the Form Interface">
    Navigate to the FAQ list and select the entry you wish to modify to load the editor.
  </Step>
  <Step title="Update Form Fields">
    Modify the necessary field values (such as question text, answer body, category, or sorting order).
  </Step>
  <Step title="Preview & Save or Publish">
    Use **Set up Preview** to check changes on the frontpage, then click **Save** to preserve edits in **Draft** state or click **Publish** to push updates live to the website.
  </Step>
</Steps>
