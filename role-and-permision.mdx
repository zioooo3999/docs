## Overview

The **Roles** page in the User Management module acts as a centralized management dashboard for defining, configuring, and assigning access permission levels across the Tempe Park CMS. This interface allows administrators to control role-based access levels, ensuring users have the appropriate privileges required for their specific responsibilities.

---

## Key Components & Capabilities

<CardGroup cols={2}>
  <Card title="Roles List Table" icon="table-list">
    Displays a structured list of all defined roles in the system, detailing:

    - **Name:** Role label (e.g., _Author_, _Editor_, _Super Admin_).
    - **Description:** Summary of responsibilities and access scopes.
    - **Users:** Count of active accounts assigned to the role.
  </Card>

  <Card title="Search Control" icon="magnifying-glass">
    Includes a **Search** bar at the top left of the table to quickly locate specific roles within the system.
  </Card>

  <Card title="Role Action Controls" icon="sliders">
    Provides quick action shortcuts for each role entry:

    - **Duplicate / Copy:** Clones an existing role and its permissions.
    - **Edit (Pencil):** Modifies role name, description, or feature permissions.
    - **Delete (Trash):** Removes a role permanently from the system.
  </Card>

  <Card title="Add New Role" icon="plus">
    Allows administrators to create custom roles from scratch via the **\+ Add new role** button at the top right or the link below the table.
  </Card>
</CardGroup>

---

<Note>
  Modifying or deleting an existing role directly affects all users assigned to that role. Verify permissions carefully before applying changes.
</Note>
