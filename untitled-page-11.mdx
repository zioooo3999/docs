## Overview

The **Plugins and Marketplace Permissions** panel controls user access to the CMS marketplace, where administrators can browse, install, and manage integration plugins, custom providers, and third-party extensions.

<Frame>
  ![Plugins and Marketplace Permissions Panel](/images/Screenshot-2026-07-29-150427.png)
</Frame>

---

## Main Panel Controls

<AccordionGroup>
  <Accordion title="Expand / Collapse Panel" icon="chevron-down">
    Located at the top-right corner of the section header. Toggles the visibility of the marketplace permission panel.
  </Accordion>

  <Accordion title="Access the Marketplace" icon="square-check">
    **Checkbox Permission:** Grants assigned roles access to open, browse, and interact with the in-app plugin marketplace.
  </Accordion>

  <Accordion title="Select All Options" icon="list-check">
    **Checkbox Action:** Selects or deselects all permissions within the Marketplace section simultaneously.
  </Accordion>

  <Accordion title="Advanced Settings Button" icon="gear">
    **Gear Icon:** Opens the advanced conditional permissions modal (_Plugins and marketplace / Marketplace_) to configure custom execution conditions.
  </Accordion>
</AccordionGroup>

---

## Advanced Conditions Modal (_Plugins and marketplace / Marketplace_)

Clicking the **Settings** gear icon opens a pop-up window to set specific conditional rules (_WHEN_) governing marketplace access.

<Frame>
  ![Plugins and Marketplace Advanced Conditions Modal](/images/Screenshot-2026-07-29-162048.png)
</Frame>

### Conditional Rule Options

| Access Condition | Description & Function |
| :-- | :-- |
| **CAN ACCESS THE MARKET... WHEN** | Dropdown field defining specific conditional rules or environmental constraints under which a user is allowed to access the marketplace. |

## Summary Reference

| Control / Element | Type | Function |
| :-- | :-- | :-- |
| **Panel Toggle** | Chevron Icon | Expands or collapses the Marketplace permissions panel. |
| **Access Marketplace** | Checkbox | Enables browsing and installing integration plugins. |
| **Select All** | Checkbox | Toggles all marketplace permissions simultaneously. |
| **Settings (Gear Icon)** | Modal Trigger | Opens conditional access rules modal (_Plugins and marketplace / Marketplace_). |
| **Apply** | Modal Button | Saves and attaches the selected conditional criteria to the permission rule. |
