## Overview

The **Media Library Plugin Permissions** setting controls user access to the CMS media asset management system. It allows administrators to define specific privileges for accessing the media repository, customizing layout views, and managing individual media assets (such as images, videos, and documents).

This ensures that asset management rights are properly regulated based on user roles and operational requirements.

## Permission Categories

| Subsection | Available Actions | Description |
| :-- | :-- | :-- |
| **1. General** | `Access the Media Library`, `Configure View`, `Select All` | Controls authorization to access the main media manager interface and customize layout/sorting preferences. |
| **2. Assets** | `Create (upload)`, `Update (crop, details, replace) + delete`, `Download`, `Copy link`, `Select All` | Manages operational authority over individual media files including uploading, editing, deleting, downloading, and link copying. |

---

## Interface Controls & Buttons

- **Expand / Collapse Toggle (Chevron Icon):** Located at the top-right corner of the section header to show or hide the permission settings panel.
- **Select All Checkbox:** Toggles all permission checkboxes within a specific subsection (_General_ or _Assets_) simultaneously.
- **Settings Button:** Opens an advanced configuration panel for granular asset-level rules and conditional access parameters.

---

<Note>
  **Asset Safety:** Granting the **Update \+ delete** permission permits permanent removal of files from the system, which may affect published pages where those assets are currently embedded.
</Note>
