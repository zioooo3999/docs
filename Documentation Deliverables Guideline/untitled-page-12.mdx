## Overview

The **Webhooks Permissions** panel manages administrative access to automated HTTP callbacks (_webhooks_) within the CMS. It determines which users can set up, view, edit, or remove webhooks used for triggering external integrations, build pipelines, and third-party automated workflows.

## Main Panel Controls

<AccordionGroup>
  <Accordion title="Expand / Collapse Panel" icon="chevron-down">
    Located at the top-right corner of the section header. Toggles the visibility of the Webhooks permission panel.
  </Accordion>

  <Accordion title="CRUD Actions (Create, Read, Update, Delete)" icon="sliders">
    - **Create Checkbox:** Grants permission to configure and register new webhooks.
    - **Read Checkbox:** Allows users to view the list of configured webhooks, target URLs, and event triggers.
    - **Update Checkbox:** Permits modifying existing webhook parameters (e.g., custom headers, triggers, or endpoint URLs).
    - **Delete Checkbox:** Allows users to remove existing webhooks from the system.
  </Accordion>

  <Accordion title="Select All Options" icon="list-check">
    **Checkbox Action:** Toggles all webhook action permissions simultaneously in a single click.
  </Accordion>

  <Accordion title="Advanced Settings Button" icon="gear">
    **Gear Icon:** Opens the advanced conditional permissions modal (_Webhooks / General_) to define execution criteria for each action.
  </Accordion>
</AccordionGroup>

## Advanced Conditions Modal (_Webhooks / General_)

Clicking the **Settings** gear icon opens a conditional rules modal to configure specific execution policies (_WHEN_) for each CRUD operation.

<Frame>
  ![Webhooks Advanced Conditions Modal](/images/Screenshot-2026-07-29-162114.png)
</Frame>

### Conditional Rule Dropdowns

| Action Condition | Description & Function |
| :-- | :-- |
| **CAN CREATE WHEN** | Sets specific conditional rules under which a user is authorized to register new webhooks. |
| **CAN READ WHEN** | Defines conditions under which a user can view existing webhooks and event triggers. |
| **CAN UPDATE WHEN** | Specifies conditions required for editing configured webhook parameters. |
| **CAN DELETE WHEN** | Establishes conditions required to remove webhooks from the CMS. |

## Summary Reference

| Control / Element | Type | Function |
| :-- | :-- | :-- |
| **Panel Toggle** | Chevron Icon | Expands or collapses the Webhooks permissions panel. |
| **Create / Read / Update / Delete** | Checkbox | Configures individual CRUD permissions for managing webhooks. |
| **Select All** | Checkbox | Bulk toggles all webhook CRUD permissions simultaneously. |
| **Settings (Gear Icon)** | Modal Trigger | Opens conditional access rules modal (_Webhooks / General_). |
| **Apply** | Modal Button | Saves and applies the configured condition rules to the webhook permissions. |
