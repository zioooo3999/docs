## Overview

The **SEO Plugin Permissions** setting controls user access to search engine optimization configuration options within the CMS. It allows administrators to grant or restrict authority to access and manage site-wide SEO configurations, ensuring search engine optimization settings are handled only by authorized roles.

## Permission Categories

| Subsection | Available Actions | Description |
| :-- | :-- | :-- |
| **GENERAL** | `Access the plugin settings`, `Select All` | Controls authorization to open, view, and modify global SEO settings and meta configurations across the CMS. |

---

## Interface Controls & Options

- **Expand / Collapse Toggle (Chevron Icon):** Located at the top-right corner of the section header to expand or collapse the permission configuration panel.
- **Access the plugin settings Checkbox:** Grants permission for users assigned to this role to open, view, and modify global SEO settings and meta configurations across the CMS.
- **Select All Checkbox:** Toggles all general SEO permissions at once with a single click.
- **Settings Button:** Opens an advanced configuration menu to set up conditional permissions or detailed parameters related to the SEO plugin.

---

<Note>
  **SEO Impact:** Global SEO configurations directly affect site indexing and search engine visibility. Restrict access to marketing managers or specialized content strategists.
</Note>
