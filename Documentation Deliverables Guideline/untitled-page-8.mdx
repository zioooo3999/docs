## Overview

The **Media Library Settings Permissions** panel controls user authority to view and configure global preferences for the CMS Media Library (such as asset optimization, responsive dimensions, or media upload settings).

It also supports **conditional permissions**, allowing administrators to refine access based on asset ownership or organizational role hierarchy.

## Advanced Conditions Modal (_Media library / General_)

Clicking the **Settings** gear icon opens a conditional rules modal to specify exact conditions under which a user can access Media Library configuration settings.

<Frame>
  ![Media Library Advanced Conditions Modal](/images/Screenshot-2026-07-29-161853.png)
</Frame>

### Conditional Rule Options

| Access Condition | Description & Behavior |
| :-- | :-- |
| **Default** | Applies standard system-wide access permissions for the assigned role. |
| **Is creator** | Restricts access strictly to settings or assets created directly by the active user. |
| **Has same role as creator** | Grants access if the active user shares the same system role as the original asset creator. |

## Summary Reference

| Control / Action | Type | Function |
| :-- | :-- | :-- |
| **Panel Toggle** | Chevron Icon | Expands or collapses the Media Library permissions panel. |
| **Access Settings Page** | Checkbox | Enables viewing and editing of global Media Library preferences. |
