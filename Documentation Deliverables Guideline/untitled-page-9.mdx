## Overview

The **Internationalization Permissions** panel controls user access to multi-language and regional settings (_locales_) within the CMS. It enables administrators to manage who can create, view, modify, or remove language locales used across content modules, as well as apply conditional rules to limit locale management under specific circumstances.

## Main Panel Controls

<AccordionGroup>
  <Accordion title="Expand / Collapse Panel" icon="chevron-down">
    Located at the top-right corner of the section header. Toggles the visibility of the Internationalization permission panel.
  </Accordion>

  <Accordion title="CRUD Actions (Create, Read, Update, Delete)" icon="sliders">
    - **Create Checkbox:** Grants permission to add new language locales to the system.
    - **Read Checkbox:** Permits viewing the list of existing configured locales and their settings.
    - **Update Checkbox:** Allows users to modify existing locale configurations (e.g., changing default locale or display names).
    - **Delete Checkbox:** Enables users to delete locales from the system.
  </Accordion>

  <Accordion title="Select All Options" icon="list-check">
    **Checkbox Action:** Toggles all locale CRUD permissions simultaneously in a single click.
  </Accordion>

  <Accordion title="Advanced Settings Button" icon="gear">
    **Gear Icon:** Opens the advanced conditional permissions modal (_Internationalization / Locales_) to set fine-grained conditions for each action.
  </Accordion>
</AccordionGroup>

## Advanced Conditions Modal (_Internationalization / Locales_)

Clicking the **Settings** gear icon opens a conditional rules modal to specify exact conditions under which a user can execute CRUD actions on locales.

<Frame>
  ![Internationalization Advanced Conditions Modal](/images/Screenshot-2026-07-29-163230.png)
</Frame>

### Conditional Rule Dropdowns

| Action Condition | Description & Function |
| :-- | :-- |
| **CAN CREATE WHEN** | Defines conditional criteria under which a user is allowed to add new locales. |
| **CAN READ WHEN** | Defines conditional criteria under which a user can view existing locale configurations. |
| **CAN UPDATE WHEN** | Defines conditional criteria under which a user can edit existing locales. |
| **CAN DELETE WHEN** | Defines conditional criteria under which a user can remove locales from the system. |

## Control Action Summary

| Control / Element | Type | Function |
| :-- | :-- | :-- |
| **Panel Toggle** | Chevron Icon | Expands or collapses the Internationalization settings panel. |
| **Create / Read / Update / Delete** | Checkbox | Configures individual CRUD permissions for managing locales. |
| **Select All** | Checkbox | Bulk toggles all CRUD actions for locale management. |
| **Settings (Gear Icon)** | Modal Trigger | Opens conditional access rules modal (_WHEN dropdowns_). |
| **Apply** | Modal Button | Saves and applies the configured condition rules to the locale permissions. |
