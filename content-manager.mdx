## Overview

The **Content Manager** page in the Strapi CMS is the central management point for all application or website content built using Strapi. Through this page, administrators and content editors can create, view, modify, and delete content data in a structured manner without needing to interact directly with the database or program code.

Content Manager displays all pre-defined Content Types (both Collection Types and Single Types), complete with fields representing data structures such as text, rich text, media, relationships between tables, and dynamic components. Each content entry is presented in an intuitive interface, facilitating consistent and secure data management.

## How to Access and Use Content Manager

Based on the overview above, follow these step-by-step procedures to utilize the Content Manager effectively:

<Steps>
  <Step title="Access the Central Management Point">
    Open the Strapi CMS and navigate to the **Content Manager** via the icon on the sidebar. This acts as your central hub for all website content.

    <Frame caption="Content Manager Sidebar Icon">
      ![Content Manager Icon](/images/Screenshot-2026-07-20-163239.png)
    </Frame>
  </Step>
  <Step title="Select Your Pre-defined Content Type">
    Choose the desired **Collection Type** or **Single Type** from the navigation list to view its pre-defined schema and structure.
  </Step>
  <Step title="Manage Content Entries Without Code">
    Create, view, modify, or delete content directly through the intuitive interface—eliminating the need to interact directly with database tables or program code.
  </Step>
  <Step title="Fill and Configure Data Fields">
    Input content into the structured fields provided by the schema, including:

    - **Text & Rich Text**: Basic titles, paragraphs, and formatted copy.
    - **Media**: Image and file uploads.
    - **Relationships & Components**: Links between tables and dynamic layout elements.
  </Step>
  <Step title="Ensure Consistent and Secure Management">
    Review your entries within the intuitive interface to maintain content consistency and data security before finalizing your changes.
  </Step>
</Steps>
