## Overview

The **Content Type Builder Plugin Permissions** setting controls access rights to the Content Type Builder tool within the CMS. This tool is responsible for defining data models, schema structures, fields, and relationships for collection types, single types, and components.

Granting access here determines whether a user role can inspect and understand the underlying content architecture of the website.

## Permission Categories

| Subsection | Available Action | Description |
| :-- | :-- | :-- |
| **GENERAL** | `Read` | Enables users assigned to this role to view and inspect existing content-types, fields, components, and data structure configurations within the Content Type Builder module. |

---

## Interface Controls & Buttons

- **Expand / Collapse Toggle (Chevron Icon):** Located at the top-right corner of the section header to expand or collapse the permission configuration panel.
- **Read Checkbox:** Grants permission to inspect schema models, attributes, and structural relationships without modifying them.
- **Select All Checkbox:** Toggles all available permissions under the **GENERAL** subsection in a single click.
- **Settings Button:** Opens an advanced configuration panel to fine-tune specific conditional permissions and parameters associated with the Content Type Builder tool.

---

<Note>
  **Architectural Integrity:** Even read-only access to the Content Type Builder provides deep insight into system data models. Ensure this visibility is limited to roles responsible for content modeling or development.
</Note>
