## Overview

The **Create a Role** feature in the User Management module allows administrators to define custom user roles with specific permissions for accessing and managing the Tempe Park CMS. By creating tailored roles, administrators can ensure that users are granted only the necessary rights corresponding to their organizational duties.

---

## Form Configuration

<Frame>
  ![Create a Role Form](/images/Group-3.png "Create a Role Form")
</Frame>

| Field / Action | Requirement | Function & Description |
| :-- | :-- | :-- |
| **Name** | _Required_ | Input a unique identifier for the role (e.g., _Content Moderator_, _Event Manager_). |
| **Description** | _Optional_ | Provide a concise summary detailing the scope of access, responsibilities, or metadata. |
| **Reset** | _Action_ | Clears all input fields in the form back to their default state. |
| **Save** | _Action_ | Stores the new role definition permanently in the system. |

---

## How to Create a Role

1. **Enter Role Name:** Input a unique identifier for the new role in the **Name** field (_required_).
2. **Provide Description:** Type a concise summary in the **Description** field (_optional_) detailing the access scope or responsibilities.
3. **Save Role:** Click the **Save** button in the top-right corner to store the new role definition in the system.

---

<Note>
  After creating a role, you can assign it to user accounts during user creation or via the **Edit User** page.
</Note>
