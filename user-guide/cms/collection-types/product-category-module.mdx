## Overview

The Product Category module is designed to manage and organize product data. It functions as a central hub for grouping products, ensuring that information on the website is structured, tidy, and easy for visitors to navigate. Administrators can add, modify, and organize these categories to align with Tempe Park’s operational requirements.

### Module Interface Functions

| No | Element | Function |
| :-- | :-- | :-- |
| **1** | **Search Button** | Searches for keywords based on `title`, `slug`, and `short_description`. |
| **2** | **Filter Button** | Performs targeted searches within a specific selected field. |
| **3** | **Checkbox Button** | Enables bulk actions (Delete, Publish, Unpublish) for multiple records. |
| **4** | **ID** | Displays the unique identifier for the category data. |
| **5** | **Name** | Shows the name of the product category. |
| **6** | **Slug** | Displays the URL slug for the product category. |
| **7** | **Products** | Indicates the products associated with this category. |
| **8** | **Status** | Indicates whether the category is Published or in Draft status. |
| **9** | **Create New Entry** | Initiates the creation of a new product category entry. |
