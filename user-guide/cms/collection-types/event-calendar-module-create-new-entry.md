## Overview

The **Create New Entry** feature in the Event/Calendar module is used to add data for new events or activities to be held at Tempe Park. This feature allows administrators to input various event information—such as event names, dates, times, locations, descriptions, and media assets—which will be displayed on the website.

Successfully added event data will be saved in the system and can be published in the calendar or event section on the Tempe Park website frontpage.

## Step-by-Step Procedure

<Steps>
  <Step title="Review the Form Interface">
    Open the Event/Calendar module from the main CMS navigation and click on **Create New Entry**.
  </Step>
  <Step title="Complete Form Parameters">
    Input all necessary event metadata including **Title**, **Slug**, **Description**, **start\_date**, **end\_date**, and **location** into the form fields.
  </Step>
  <Step title="Add Media & Translations">
    Upload the **Cover image**, set the **event\_tipe**, and use the **Multilingual** switcher to configure language versions if needed.
  </Step>
  <Step title="Save or Publish">
    Click **Save** to keep the entry in a draft state for internal review, or click **Publish** to make the event live on the Tempe Park calendar section.
  </Step>
</Steps>
