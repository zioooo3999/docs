## Overview

The Product module serves as the central repository for all product information on the Tempe Park website. It manages core details including product names, descriptions, images, pricing, categories, and direct links to the integrated e-commerce platform.

By establishing relationships with the **Product Category** module, administrators can organize products into specific groups, ensuring an intuitive browsing experience for visitors.

### Module Interface Functions

| No | Element | Function |
| :-- | :-- | :-- |
| **1** | **Search Button** | Searches for keywords across general information fields: `title`, `slug`, and `short_description`. |
| **2** | **Filter Button** | Performs targeted searches within a specific selected field. |
| **3** | **Checkbox Button** | Enables bulk actions (Delete, Publish, Unpublish) across multiple records simultaneously. |
| **4** | **ID** | Displays the unique identifier for the product data. |
| **5** | **Product Name** | Shows the name of the product. |
| **6** | **Product Category** | Displays the assigned category for the product. |
| **7** | **Images** | Shows the product's associated imagery. |
| **8** | **Status** | Indicates whether the data is currently Published or in Draft status. |
| **9** | **Create New Entry** | Initiates the creation of a new product entry in the system. |
