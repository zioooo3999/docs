## Overview

The **Create New Entry** button in the News Category module is used to add a new news category to the system. This feature allows administrators to input category information, such as the category name and slug identifier.

The news category data that is successfully added will be stored in the system and can be used in the News module as a grouping mechanism for news content displayed on the Tempe Park website.

---

## Form Fields & Interface Reference

<Frame>
  ![New News Category Page](/images/0-\(43\).png "New News Category Page")
</Frame>

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1** | **Tab Draft** _(editable form)_ | Use this form tab when creating or modifying a draft data entry. |
| **2** | **Tab Published** | Read-only view showing the current published version of the news category. |
| **3** | **Name** | Enter the primary name of the news category. |
| **4** | **Slug** | Enter the URL-friendly slug identifier for the news category. |
| **5** | **Publish** | Instantly publishes entry to the website frontpage and enables cross-module relationships. |
| **6** | **Save** | Stores the entry as a **Draft** without making it publicly visible. |
| **7** | **Multilingual** | Switch or add content versions in **English**, **Indonesian**, or **Chinese**. |

---

## Step-by-Step Procedure

<Steps>
  <Step title="Review the Form Interface">
    Open the News Category module from the CMS navigation bar and click on **Create New Entry**.
  </Step>
  <Step title="Input Category Name & Slug">
    Enter the category **Name** and the URL-friendly **Slug** identifier into the form fields.
  </Step>
  <Step title="Configure Multilingual Versions">
    Click the **Multilingual** button to add corresponding localized translations in English, Indonesian, or Chinese if applicable.
  </Step>
  <Step title="Save or Publish">
    Click **Save** to preserve the entry as a draft, or click **Publish** to deploy the new category live to the website.
  </Step>
</Steps>
