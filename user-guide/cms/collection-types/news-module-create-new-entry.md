## Overview

The **Create New Entry** button in the News module is used to add new news data to the system. This feature allows administrators to input various news information, such as the title, content, image, publication date, author, and other supporting metadata to be displayed on the website.

Successfully added news data will be stored in the system and can be published on the Tempe Park website news page as the latest information for visitors.

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1** | **Tab Draft** _(editable form)_ | Use this form tab when creating or modifying a draft data entry. |
| **2** | **Tab Published** | Read-only view showing the current published version of the news article. |
| **3** | **Title** | Enter the primary news article title. |
| **4** | **Excerpt** | Enter a brief summary or preview description for article cards. |
| **5** | **Content** | Input the full news body text and main article description. |
| **6** | **Slug** | Enter the URL-friendly slug identifier for the news post. |
| **7** | **Publish** | Instantly publishes entry to the website frontpage and enables cross-module relationships. |
| **8** | **Save** | Stores the entry as a **Draft** without making it publicly visible. |
| **9** | **Multilingual** | Switch or add content versions in **English**, **Indonesian**, or **Chinese**. |
| **10** | **cover\_image** | Upload or attach the main cover media file for the news header and thumbnail. |
| **11** | **author** | Enter the name of the news author or contributor. |
| **12** | **published\_date** | Select or enter the scheduled publication date. |
| **13** | **category** | Assign the relevant news category. |
| **14** | **Tags** | Add searchable keywords and tag metadata. |

## Step-by-Step Procedure

<Steps>
  <Step title="Review the Form Interface">
    Open the News module from the CMS navigation bar and click on **Create New Entry**.
  </Step>
  <Step title="Input Article Content & Metadata">
    Fill in the **Title**, **Slug**, **Excerpt**, and full **Content** body text.
  </Step>
  <Step title="Configure Author, Media & Taxonomy">
    Upload the **cover\_image**, specify the **author** and **published\_date**, and assign appropriate **category** and **Tags**.
  </Step>
  <Step title="Save or Publish">
    Click **Save** to preserve the draft, or click **Publish** to deploy the news entry live to the website.
  </Step>
</Steps>
