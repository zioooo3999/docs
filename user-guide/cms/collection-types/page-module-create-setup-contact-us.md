## Overview

The **Create/Setup Contact Us** feature allows administrators to design the Contact Us page using the Page Builder. This module enables the integration of a hero section and a dedicated "Let's Connect" inquiry form, providing a streamlined way for visitors to communicate with the organization.

<Tip>
  Use **Save button** to keep content as Draft, or **Publish** when the data is ready to appear on the website frontpage.
</Tip>

---

## Form Configuration

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1-2** | **Tabs** | Switch between **Draft** (editable) and **Published** (read-only view). |
| **3-4** | **Title / Slug** | Define the page title and unique URL slug. |
| **5-6** | **SEO** | Click `(+)` to configure `metaTitle`, `metaDescription`, and `shareImage`. |
| **7** | **Add Component** | Access structural building blocks for the page. |
| **10** | **Multilingual** | Toggle between English, Indonesian, and Chinese versions. |

## Section Builder Guide

### 1. Hero Section

- **Access:** Use the **Shared** group (11) and select **Page Header** (12).
- **Fields:** Upload the **background\_image** (14/15), toggle **navigation\_tabs** (16), and enter the **page\_title** (17).

### 2. Let's Connect Section

- **Access:** Select the **Contact** component group (18) and choose **Contact Us** (19).
- **Content Settings:**
  - Set the **eyebrow** (20), **heading** (21), and **image** (22) for the section header.
- **Form Field Labels:** Configure the localized labels for:
  - `name_label` (23), `email_label` (24), `phone_label` (25), `topics_label` (26), and `notes_label` (27).
- **Placeholders:** Define user-friendly input hints for:
  - `name_placeholder` (28), `email_placeholder` (29), `phone_placeholder` (30), `topics_placeholder` (31), and `notes_placeholder` (32).
- **Submission Settings:**
  - Set the **cta\_label** (33) for the submit button.
  - Configure the **success\_message** (34) and **error\_message** (35) to handle form submission feedback.

<Warning>
  Always verify that all form labels and placeholders are translated accurately across all multilingual tabs to ensure a consistent user experience.
</Warning>
