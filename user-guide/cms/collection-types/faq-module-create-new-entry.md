## Overview

The **Create New Entry** button in the FAQ module is used to add new questions and answers to be displayed on the Tempe Park website. This feature allows administrators to input various FAQ information—such as questions, answers, and FAQ categories—as needed.

Successfully added FAQ data will be stored in the system and can be published on the Tempe Park website as information for visitors.

---

## Form Fields & Interface Reference

<Frame>
  ![New FAQ Page](/images/0-\(28\).png "New FAQ Page")
</Frame>

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1** | **Tab Draft** _(editable form)_ | Use this form tab when creating or modifying a draft data entry. |
| **2** | **Tab Published** | Read-only view showing the current published version of the FAQ entry. |
| **3** | **Question** | Enter the primary FAQ question text. |
| **4** | **Answer** | Enter the detailed answer or response text. |
| **5** | **Publish** | Instantly publishes entry to the website frontpage and enables cross-module relationships. |
| **6** | **Save** | Stores the entry as a **Draft** without making it publicly visible. |
| **7** | **Category** | Assign or enter the appropriate FAQ category. |
| **8** | **Order** | Set the numerical display sequence/priority for ordering questions. |
| **9** | **Multilingual** | Switch or add content versions in **English**, **Indonesian**, or **Chinese**. |

---

## Step-by-Step Procedure

<Steps>
  <Step title="Review the Form Interface">
    Open the FAQ module from the CMS navigation bar and click on **Create New Entry**.
  </Step>
  <Step title="Input Question & Answer Details">
    Fill in the **Question** and **Answer** fields with concise, accurate information.
  </Step>
  <Step title="Set Category, Order & Language">
    Select the **Category**, enter a numerical **Order** for sorting priority, and configure language translations via the **Multilingual** switcher.
  </Step>
  <Step title="Save or Publish">
    Click **Save** to preserve the entry as a draft, or click **Publish** to make the FAQ live on the website.
  </Step>
</Steps>
