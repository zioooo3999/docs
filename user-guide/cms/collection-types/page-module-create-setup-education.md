## Overview

The **Create/Setup Education** feature in the Page module allows you to create a new Education page and structure the content of the Tempe Park website's Education frontpage using the Page Builder. This feature enables administrators to add various sections—such as a hero header, History of Tempe, Fun Facts, Tempe Warriors & Heroes, and School Programs—to suit the website's visual and informational needs.

Administrators can organize content, section order, and page layout to ensure information is presented in an attractive, dynamic, and intuitive manner for visitors.

<Tip>
  Use **Save button** to keep content as Draft, or **Publish** when the data is ready to appear on the website frontpage.
</Tip>

## Page Configuration

| No | Field / Element | Function & Description |
| :-- | :-- | :-- |
| **1-2** | **Tabs** | Switch between **Draft** (editable) and **Published** (read-only view). |
| **3-4** | **Title / Slug** | Define the page title and unique URL slug. |
| **5-6** | **SEO** | Click `(+)` to configure `metaTitle`, `metaDescription`, and `shareImage` for search engine indexing. |
| **7** | **Add Component** | Access the library of structural building blocks for the Page Builder. |
| **8-9** | **Publish / Save** | Push content live immediately or save changes as a draft. |
| **10** | **Multilingual** | Toggle between English, Indonesian, and Chinese versions. |

## Section Builder Guide

### 1. Hero Section

- **Access:** Use the **Shared** group (11) and select **Page Header** (12).
- **Fields:** Upload the **background\_image** (14/15), enable **navigation\_tabs** (16) if required, and enter the **page\_title** (17).

### 2. History Section

- **Spacing & Access:** Add a **Spacer** component (18) and set its **height** (19). Then select the **education** component group (20) and choose the **History Section** (21).
- **Cards:** Click `(+)` on the cards field (22) to add historical entries, filling in the **heading** (23), **image** (24), and **body** (25). Use **Add an entry** (26) to add multiple items.
- **Section Headers:** Configure the section **eyebrow** (27) and **heading** (28).

### 3. Fun Fact Section

- **Access:** Select the **Fun Facts Section** component group (29).
- **Cards:** Click `(+)` on the card field (30) to populate statistics or facts using **icon** (31), **heading** (32), and **description** (33). Use **Add an entry** (34) for multiple cards.
- **Section Headers:** Define the **eyebrow** (35) and **heading** (36).

### 4. Warriors Section

- **Access:** Select the **Warriors Section** component group (37).
- **Entries:** Click `(+)` on the warriors field (38) to add character details, including **name** (39), **role\_title** (40), **description** (41), and **photo** (42). Use **Add an entry** (43) to include more profiles.
- **Section Headers:** Set the section **eyebrow** (44) and **heading** (45).

### 5. School Program Section

- **Access:** Select the **School Section** component group (46).
- **Content:** Enter the program **description** (47), upload an **image** (48), set the section **eyebrow** (49) and **Heading** (50), and configure the **item\_learn\_more\_label** (51) for the CTA button.

<Warning>
  Always verify your content entries and asset uploads across all language tabs before hitting **Publish**.
</Warning>
