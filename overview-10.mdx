## Overview

The **Users** page in the User Management module serves as a centralized dashboard for managing all administrative accounts that have access to the Tempe Park CMS admin panel. This interface provides administrators with full visibility and control over user credentials, permissions, and account statuses to maintain system security and efficient workflow delegation.

---

## Key Components & Capabilities

<CardGroup cols={2}>
  <Card title="User List Table" icon="table-list">
    Displays a structured overview of all registered administrators, including **First Name**, **Last Name**, **Email**, assigned **Roles** (_Super Admin_, _Author_, _Editor_), **Username**, and current **User Status** (_Active_ or _Inactive_).
  </Card>

  <Card title="Search & Filter Controls" icon="magnifying-glass">
    Allows administrators to quickly locate specific accounts using the **Search** bar or apply custom parameters via the **Filters** tool to refine the list by role or status.
  </Card>

  <Card title="User Action Controls" icon="sliders">
    Provides direct action shortcuts for each user entry in the table, enabling administrators to **Edit** user profiles/permissions or **Delete** accounts.
  </Card>

  <Card title="Invite New User" icon="user-plus">
    Features a prominent **Invite new user** button at the top right, allowing authorized admins to send access invitations and register new accounts to the CMS.
  </Card>
</CardGroup>

<Note>
  Regularly audit active user accounts and their associated roles to maintain strict access security across the CMS.
